# aBangumi 1.2.0 更新报告

发布日期：2026-08-31

## 重点更新

- 完成整体 UI 重构，强化朱红强调色、信息层级、卡片辨识度与页面切换动画。
- 新增平板响应式布局：左侧主控制栏、搜索分类侧栏，以及排行榜、每日放送、收藏与讨论的宽屏高密度展示。
- 排行榜支持滚动收起顶部信息、下拉刷新和继续加载；手机底部导航会在向上滚动时自动隐藏。
- 发现页加入热门条目与热门讨论；热门条目在平板以横向两排展示，讨论使用双列并支持滚动加载更多。
- 条目社区加入讨论、吐槽和长评入口，正文支持 Markdown、Bangumi 表情及图片。
- 搜索扩展到角色和人物，并在用户已登录时携带会话读取需要认证的搜索结果与条目数据。
- 新增个人资料页；压缩“我的”页资料区和筛选区，平板收藏列表改为双列。
- 改进条目封面和资源图比例处理，兼容超长图、宽图与常规海报；详情封面支持全屏展开。

## 性能与稳定性

- 新增匿名页面动态 JSON 缓存，刷新操作可强制绕过缓存。
- 限制 Flutter 图片缓存数量与内存上限，降低长时间浏览后的内存占用。
- 认证内容不写入匿名页面缓存，避免用户数据混入公共缓存。
- 统一页面返回、主导航切换和内容进入动画。

## OA/BFF 与 API

- 官方构建默认连接 `https://api.anjila.icu`，公开 Client ID 为
  `bgm69386a8765324f840`。
- GitHub Actions Release 构建会注入上述公开配置，也可通过仓库变量覆盖。
- BFF 新增 `/api/bangumi-p1/*` 固定源代理，将认证后的发现与社区请求安全转发到
  `https://next.bgm.tv/p1/*`。
- `/api/bangumi/*` 继续代理官方 `https://api.bgm.tv/*`，两类代理共用服务端持有的
  OAuth access token 与自动刷新流程。
- `BANGUMI_CLIENT_SECRET` 不进入客户端、Git 仓库或 GitHub Actions，仅保存在 OA
  服务器部署环境。

## 部署提示

- OA/BFF 当前使用内存会话存储，服务器重启会使已有会话失效；多实例或长期生产部署建议迁移到 Redis/数据库。
